Good to know

Do I need to be confident with technology?

The short guide explains each step. Simple mode uses just a few clearly labelled buttons for training. You can also go through the setup with someone you trust.

Do I need a new account?

Local training does not need a separate PhysioClock account. Reminders, Apple Health steps and syncing through your Apple Account are optional extras.

Can I use more features later?

Yes. Switch to full mode and back under Help → Settings → Display mode. Switching does not end a running session.

How do I save an edited template?

In simple mode: Edit exercises → Save under a new name → enter a name → Save. Find the new set under Choose a programme. The template is kept.
