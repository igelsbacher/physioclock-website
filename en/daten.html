04 / 06 · About 7 minutes · Import, backup and iCloud

Take your data with you

  1. Import a new set

    Download a template below and save it in Files. In the app, open Help & Information → Backup & Deletion → Import as new set (CSV / JSON). Choose the file, name the set and confirm Add set. Existing sets, history and the active plan stay in place.

  2. Export a backup

    Under Backup, choose Export backup. Save the JSON file somewhere protected. It contains the current plan, sets, custom catalogue exercises and history, but not every app setting. The current importer creates a set from it; it does not restore all history.

  3. Enable iCloud

    Use the same Apple Account on iPhone and iPad and enable iCloud Drive. Open Reminders & iCloud on both devices and enable iCloud sync. Tap Sync now and read the status. This requires the app’s CloudKit service to be configured correctly.

  4. Understand sync

    Sync runs on opening and periodically in the foreground. Offline changes stay local and transfer later. A running timer does not transfer; sync waits during running or paused training. The latest change wins when the same entry is edited on both devices. Avoid editing the same set in parallel.

  5. Disabling is different from deleting

    Disabling sync does not delete cloud data. Deleting synced entries may affect the other device too. Export important data first. To remove all cloud data, disable sync on every device and use iCloud storage management. A device still syncing could upload data again.

Try it yourself

Import the JSON example as Practice. Check that your existing sets remain. Optionally create a test set on device A, sync both open apps and find it on device B.

What success looks like

The import appears as an additional set. During the optional iCloud test, the test set also appears on device B and the status reports a successful sync.
