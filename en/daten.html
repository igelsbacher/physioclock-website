04 / 06 · About 7 minutes · Import, backup and iCloud

Take your data with you

  1. Import a new set

    Download a template below and save it in Files. In the app, open Help & Information → Backup & Deletion → Import as new set (CSV / JSON). Choose the file, name the set and confirm Add set. Existing sets, history and the active plan stay in place.

  2. Export a backup

    Under Backup, choose Export backup. Save the JSON file somewhere protected. It contains the current plan, sets, custom catalogue exercises and history, but not every app setting. The current importer creates a set from it; it does not restore all history.

  3. Enable iCloud

    Use the same Apple Account on iPhone and iPad and enable iCloud Drive. Open Reminders & iCloud on both devices and enable iCloud sync. Tap Sync now and read the status. This requires the app’s CloudKit service to be configured correctly.

  4. Understand sync

    In “Always”, data sync runs on opening and periodically in the foreground; in “Manual”, only after “Sync now”. Offline changes stay local and transfer later. A running timer does not transfer; sync waits during running or paused training. The latest change wins when the same entry is edited on both devices. Avoid editing the same set in parallel.

  5. Disabling is different from deleting

    Disabling sync does not delete cloud data. Deleting synced entries may affect the other device too. Export important data first. To remove all cloud data, disable sync on every device and use iCloud storage management. A device still syncing could upload data again.

Try it yourself

Import the JSON example as Practice. Check that your existing sets remain. Optionally create a test set on device A, sync both open apps and find it on device B.

What success looks like

The import appears as an additional set. During the optional iCloud test, the test set also appears on device B and the status reports a successful sync.

These guides describe PhysioClock 3.23.0, build 56. Reminders, iCloud and Apple Health are optional and depend on your settings and system permissions.

Synchronisation and device activity

Always

Local data and iCloud are compared when opening the app and returning to the foreground. During use, changes sync automatically, at the latest during the next periodic sync.

Manual

Training data is sent and loaded only with “Sync now”. Local changes stay on this device until then. Activity checks for the startup warning still run automatically. This choice applies only to this device.

“Active” means the app is in the foreground and recently reported through iCloud. Status refreshes about every 45 seconds and expires after 150 seconds without a heartbeat. Internet, the same Apple Account, enabled sync and this feature on both devices are required. The warning does not lock devices.

Synchronisation and device activity

A calmer, more reliable experience

After reopening, resume or discard an interrupted session. A local checkpoint is saved about every five seconds and at pause, navigation and app-background transitions. The last seconds may be missing after an abrupt exit. Only captured time and active segments are restored; time since saving does not count. A paused session stays paused. Pending optional-exercise or cool-down choices remain choices and start nothing automatically. Training-data sync is blocked while recovery is undecided or a restored session is active.

The compact summary shows recorded active training time, movement elements run to their end and progress towards your current personal time goal. Skipped elements are not completed. A repeated element counts at most once as completed; its repeated active time still counts. Cool-down appears separately and adds no training minutes. This is a time and control summary, not an assessment of movement quality or health outcomes.

Meditation music fades gently during the final five seconds and stops with the timer. The selected duration and music on/off choice are remembered on this device for the next offer. Even after restarting, cool-down begins only after confirmation.

Removing an exercise in either editor shows Undo for eight seconds. It restores the last removed exercise with its details near its former position. With multiple removals, Undo applies to the last one. Saving or closing the editor ends the offer.

The eye control in the overview and Help → Settings hide wellbeing, steps, personal goals and their history views, including from VoiceOver. Goal progress in the summary is hidden too. The goal-widget cache is cleared; iOS controls when an already visible widget refreshes. This is a local display option, not an access lock or deletion. Existing data, explicitly requested exports and sync remain available. Training name, timer and active duration remain visible.
