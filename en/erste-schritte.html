Your first exercise set

  1. Find your way around

    Open PhysioClock. The main screen shows the time, estimated training end, current exercise, remaining time and progress. Choose German, English, French or Italian under Help & Information → Language.

  2. Build your exercise list

    Open the edit icon. Add catalogue exercises or create your own. Set each name, body region and duration. Arrange the list in the order you want, then tap Done.

  3. Save a set

    Open Training Sets using the stack icon. Choose Save current training as a new set, give it a clear name and save. A set holds the complete exercise sequence and its durations.

  4. Use it again

    Open Training Sets and tap Load for the set you want. Edit exercises changes the saved template. Rename and Delete set are in the three-dot menu. Deleting a set does not remove training history.

Try it yourself

For a practice task, create a short list of two entries and save it as Interface test. Load that set again without starting a workout.

What success looks like

The set name appears in the list. Loading it shows the saved exercises in the correct order with their durations.
