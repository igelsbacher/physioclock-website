Help and usage guide

Get started – step by step

Take your time. You do not need to learn every feature at once.

Read the step-by-step guide

Choose a language

Go to Help & Information → Language to select German, English, French or Italian.

Edit training

Tap the edit icon to adjust duration, order and body part, or select exercises from the catalogue with checkboxes.

Manage training sets

Use the stacked-layers icon to create named sets, load, edit, rename or delete them.

Start training

Start your programme; the finish time and two progress bars are calculated automatically.

Training history

The monthly calendar shows completed minutes. You can delete individual sessions.

Back up data

Use Help & Information → Backup & Deletion to export or import JSON data.

Import as a new training set

CSV and JSON import: each import adds one newly named training set. Existing data is preserved.

Steps today

Shows steps available in Apple Health since midnight in your local time zone. Updates when opened and about every minute. Steps do not change training minutes or the goal ring.

PhysioClock reads steps only and writes no Health data. The step count is displayed temporarily and is not stored, exported or transferred through PhysioClock iCloud sync.

Access is optional. A dash replaces zero when no readable data is available. Health does not let the app distinguish denied read access from missing data. Manage permissions in Apple Health.
