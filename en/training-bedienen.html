Control your training

  1. Start and read the display

    Load your prepared set and tap Start. The large countdown shows the time left for the current exercise. Separate progress indicators show the exercise and the whole session.

  2. Pause and skip

    Pause stops the session temporarily; Resume continues it. Next skips the current exercise. Skipped time does not count as active training. Reset discards an unfinished session.

  3. Finish and review

    End finishes a started session and saves it as ended early if it is not complete. A normally completed session is also recorded. Open the monthly view using the calendar icon.

  4. Signals and screen

    Configure sound and vibration in the exercise editor. iOS notifications, silent mode and Focus can affect signals. On iPhone, landscape view is available when rotation is unlocked. Check signals before first use.

Try it yourself

Use a short test set: Start → Pause → Resume → End. Check the calendar afterwards. Delete the test record from history if you do not want to keep it.

What success looks like

The countdown stops while paused. After End, the started session appears in history; only active time counts.
