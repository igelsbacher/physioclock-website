Display mode

Get started – step by step

Take your time. You do not need to learn every feature at once.

Read the step-by-step guide

Simple or full – you choose.

The first time you open this version, the mode choice appears before the existing start screens. It is saved on this device. Existing users also choose once. New users then separately acknowledge the usage notice.

Simple mode

Large text, high contrast and a few clearly labelled buttons. Choose a programme and start training.

Full mode

All existing views and features: goals, calendar, reviews and additional settings.

How it works

1. Choose a programme or edit exercises. 2. Open training. 3. Press Start. Opening training alone does not start the timer.

Pause stops the timer. Next skips the current exercise. End finishes the session and records actual movement time. Optional exercises are offered at the end.

End the running or paused session before changing programmes or editing exercises.

Simple mode skips the start animation and automatic calendar. It takes you straight to your programme overview. Privacy, data management, reminders and iCloud remain accessible under Help.

Settings

Change the mode anytime under Help → Settings → Display mode. Switching does not end a session or delete data.

High contrast is always active in this mode. You do not need to distinguish colours to use it.

Simple mode reduces visible elements while preserving the existing training sequence. Enabled rounds, rests, side changes, optional exercises and signals still apply. Choosing a mode does not change permissions and is not transferred by PhysioClock iCloud sync.

Help

How do I save an edited template?

In simple mode: Edit exercises → Save under a new name → enter a name → Save. Find the new set under Choose a programme. The template is kept.
