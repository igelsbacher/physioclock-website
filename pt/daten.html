Dados e cópia de segurança

Guarda planos, programas, exercícios próprios e sessões num ficheiro JSON. Pode conter informações sensíveis sobre as tuas atividades.

Abre Ajuda e informações → Cópia de segurança e eliminação → Importar como novo programa (CSV / JSON). Escolhe o ficheiro, o nome e confirma. Cada importação adiciona um programa sem substituir dados nem o plano ativo. Exportar JSON cria uma cópia completa; importar JSON não a restaura integralmente.

Exporta todos os dados como JSON em Ajuda e informações → Cópia de segurança e eliminação. Importar CSV ou JSON adiciona sempre um programa; os dados existentes não mudam.

Cada importação cria um programa novo. Os programas, histórico, definições e plano ativo existentes não mudam. São aceites CSV e JSON.

Elimina planos, programas guardados, catálogo personalizado e histórico completo, incluindo totais mensais. Não é possível anular.
