Confidentialité

Les données d’entraînement sont stockées localement. Si tu actives la synchronisation iCloud, les programmes, exercices personnels, historique, réglages d’entraînement et horaires de rappel sont également stockés chez Apple dans la base CloudKit privée de ton compte Apple. Aucun échange de ce type sans activation. L’autorisation de notification est propre à chaque appareil. Désactiver la synchronisation ne supprime pas les données déjà présentes dans iCloud. Elles peuvent être supprimées via la gestion du stockage iCloud, dont la présentation dépend du système. Aucun compte PhysioClock distinct, aucune publicité ni accès à la localisation. Conserve tes exports en sécurité. GitHub Pages peut traiter des données de connexion lors de la visite du site. Contact : iphysioclock@gmail.com.

Objectifs

L’objectif est également transféré si iCloud est activé. L’export JSON contient l’objectif ; l’import crée toujours un nouveau programme et ne restaure pas entièrement objectifs ou historique. Supprimer l’objectif conserve les séances. Supprimer une séance réduit la progression calculée.

Cet aperçu utilise des exemples. Il ne lit pas les données de l’application et n’enregistre pas tes réponses.

Ressenti et historique

Entrées et notes sont locales. Si iCloud est activé, elles sont aussi synchronisées dans la base privée de ton compte Apple. L’export JSON les contient. L’import actuel crée un nouveau programme et ne restaure pas l’historique du ressenti. Supprimer toutes les données supprime aussi le ressenti et les notes.
