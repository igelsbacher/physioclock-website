Bon à savoir

Faut-il être à l’aise avec la technologie ?

Le guide présente chaque étape. En mode simple, quelques boutons clairement nommés suffisent pour la séance. Vous pouvez aussi découvrir les réglages avec une personne de confiance.

Faut-il un nouveau compte ?

Aucun compte PhysioClock distinct n’est nécessaire pour les séances locales. Rappels, pas Apple Santé et synchronisation via votre compte Apple sont facultatifs.

Puis-je utiliser plus de fonctions ensuite ?

Oui. Passez au mode complet et revenez au mode simple dans Aide → Réglages → Mode d’affichage. Ce changement ne termine pas une séance en cours.

Comment enregistrer un modèle modifié ?

En mode simple : modifier les exercices → Enregistrer sous un nouveau nom → saisir le nom → Enregistrer. Retrouvez la copie dans Choisir un programme. Le modèle est conservé.
