Mode d’affichage

Bien commencer – étape par étape

Prenez votre temps. Inutile de découvrir toutes les fonctions à la fois.

Lire le guide étape par étape

Simple ou complet : à vous de choisir.

Au premier lancement de cette version, le choix du mode précède les écrans de démarrage habituels. Il est enregistré sur cet appareil. Les utilisateurs existants choisissent aussi une fois. Les nouveaux utilisateurs confirment ensuite séparément la notice d’utilisation.

Mode simple

Grands caractères, contraste élevé et quelques boutons clairement nommés. Choisissez un programme et lancez la séance.

Mode complet

Toutes les vues et fonctions habituelles : objectifs, calendrier, bilans et réglages supplémentaires.

Mode d’emploi

1. Choisissez un programme ou modifiez les exercices. 2. Ouvrez la séance. 3. Appuyez sur Démarrer. Ouvrir la séance ne lance pas le minuteur.

Pause arrête le minuteur. Suivant passe à l’exercice suivant. Terminer clôt la séance et enregistre le temps de mouvement réel. Les exercices facultatifs sont proposés à la fin.

Terminez la séance en cours ou en pause avant de changer de programme ou de modifier les exercices.

Le mode simple passe l’animation et le calendrier automatiques pour ouvrir directement l’aperçu du programme. Confidentialité, gestion des données, rappels et iCloud restent accessibles dans Aide.

Réglages

Vous pouvez changer de mode dans Aide → Réglages → Mode d’affichage. Ce changement ne termine pas la séance et ne supprime aucune donnée.

Le contraste élevé reste actif dans ce mode. Il n’est pas nécessaire de distinguer les couleurs pour l’utiliser.

Le mode simple réduit les éléments affichés tout en conservant le déroulement prévu. Tours, pauses, changements de côté, exercices facultatifs et signaux restent actifs. Le choix du mode ne modifie pas les autorisations et n’est pas transféré par la synchronisation iCloud de PhysioClock.

Aide

Comment enregistrer un modèle modifié ?

En mode simple : modifier les exercices → Enregistrer sous un nouveau nom → saisir le nom → Enregistrer. Retrouvez la copie dans Choisir un programme. Le modèle est conservé.
