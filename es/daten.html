Datos y copia de seguridad

Guarda planes, programas, ejercicios propios y sesiones en un archivo JSON. Puede contener información sensible sobre tus actividades.

Abre Ayuda e información → Copia de seguridad y eliminación → Importar como nuevo programa (CSV / JSON). Elige archivo, nombre y confirma. Cada importación añade un programa sin sustituir datos ni el plan activo. Exportar JSON crea una copia completa; importar JSON no la restaura íntegramente.

Exporta todos los datos como JSON desde Ayuda e información → Copia de seguridad y eliminación. Importar CSV o JSON siempre añade un programa; los datos existentes no cambian.

Cada importación crea un programa nuevo. Los programas, historial, ajustes y plan activo existentes no cambian. Se admiten CSV y JSON.

Elimina planes, programas guardados, catálogo personalizado e historial completo, incluidos los totales mensuales. No se puede deshacer.
