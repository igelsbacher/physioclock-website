Aiuto e istruzioni

Scegliere la lingua

Apri Aiuto e informazioni → Lingua e scegli una delle quattro lingue.

Modificare l’allenamento

Tocca l’icona di modifica per cambiare durata, ordine e parte del corpo oppure scegliere esercizi dal catalogo tramite caselle di controllo.

Gestire i set

Usa l’icona dei livelli sovrapposti per creare, caricare, modificare, rinominare o eliminare i set.

Iniziare

L’ora di fine e le due barre di avanzamento vengono calcolate automaticamente.

Storico

Il calendario mostra i minuti svolti; puoi eliminare singole sessioni.

Backup

Apri Aiuto e informazioni → Backup ed eliminazione per esportare o importare i dati JSON.

Importa come nuovo set

Importazione CSV e JSON: ogni importazione aggiunge un nuovo set con nome, mantenendo invariati i dati esistenti.

Supporto e contatti: iphysioclock@gmail.com

Classificazione medica

PhysioClock serve a organizzare esercizi scelti dall’utente, misurarne la durata e registrare il tempo di allenamento.

Classificazione medica e Swissmedic

Commissione europea: MDCG 2019-11

Scarica i modelli di allenamento

CSV

Modello CSV con quattro esempi linguistici. Importalo in PhysioClock come nuovo set, senza modificare i dati esistenti.

Scarica il modello CSV

JSON

File JSON di esempio. L’importazione aggiunge un nuovo set senza sostituire set, esercizi o cronologia esistenti. Il backup JSON completo può essere esportato separatamente.

Scarica il file JSON di esempio
